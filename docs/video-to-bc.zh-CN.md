# 从视频素材到机器人 BC 数据

本阶段交付的是裁剪后的手部动作、对应可见结果及来源索引。它们可用于动作理解、视觉表征和重定向参考，尚不能直接作为机器人关节动作的监督标签。

## 一条素材的最小记录

| 字段 | 含义 |
|---|---|
| source_url / source_sha256 | 原始视频来源及本地文件身份 |
| start_s / end_s / fps / frame_count | 原始时间轴上的区间，不人为移动动作与结果的相对时间 |
| hand_crop / result_crop | 实际像素裁剪框，必须与输出尺寸一致 |
| hand / result / paired | 独立手部、结果、并排回看；并排片只用于审核 |
| source_kind | 作者拍摄画中画、系统教学演示或静态说明卡；不凭外观推定真实控制链 |
| gesture / observed_result | 手部动作与实际可见结果分别标注；不能用章节名代替结果 |
| visibility / pairing_confidence | 遮挡、手指截断、转场和时间同步的限制 |
| robot_action_labels_available | 此阶段恒为 false |
| training_eligible_for_robot_action_bc | 此阶段恒为 false |

系统教学卡可以解释手势语义；只有能连续看到动作的区间才进入运动重定向候选。画中画与桌面共享时间轴只表示剪辑中的同步，不证明源视频没有延迟或后期处理。未展示触控板的屏幕变化不能补造成手部动作。

## 转换与验收顺序

1. 在清晰的手部片段上估计带置信度的关键点。单目尺度、遮挡手指和接触深度均保留不确定性；必要时用实测板尺寸及额外示范补齐。
2. 以食指指腹相对板面的轨迹、手指姿态和抬落时序为目标，解完整机械臂与 Sharpa 的约束重定向。安装位姿、关节限位、自碰撞、其他手指净空都参与约束。
3. 用关节目标驱动仿真器执行，记录实际关节状态、接触、设备识别、屏幕图像和结果。关节瞬移或直接设置光标不能作为成功示范。
4. 只有物理动作有效、接触可靠且 GUI 结果符合目标的完整 episode 才成为机器人 BC 候选。失败和中断保留单独索引；帧、增强副本和动作窗口不计为新的独立示范。
5. 学生实际 roll-in 后再收集纠错状态及专家标签，记录谁生成纠错、从哪个学生检查点产生。追加专家轨迹本身不叫 DAgger。

## 学习与评测

第一阶段动作范围是单指落指、滑动、抬起和点按。拖拽与多指素材先保留，暂不混入第一阶段成功数。策略观察包含屏幕相机、腕部相机、机器人本体状态及明示的接触信号；GUI 内部真值仅用于教师、奖励和评测，不能无标记进入视觉学生输入。

先完成 BC 和纠错数据闭环，再引入带示范约束的 PPO 或其他 RL。比较 BC、BC+纠错、BC+纠错+RL；世界模型作为单独消融。若 BC 使用动作块，RL 必须采用与之相容的动作概率和执行时序，不能直接套单步 PPO 比率。

按源视频/原始录制会话划分数据，再按任务、安装位置、板面姿态、相机视角、光标增益和识别延迟建立独立评测。相邻片段或同一源帧的裁剪不能同时进入训练与测试。报告目标点击率、落指/抬起错误、误点、滑动中断、重落指恢复、完成时间及完整任务分母。

原视频与裁剪素材保留在本地研究素材库。公开仓库仅存可复现工具、来源链接、协议及结果摘要；本轮不发布第三方原始视频。
