# 离线图像解码耗时诊断

背景：低目标力教师四个方向中三例通过，一例因 322.168 ms 图像年龄超过冻结的 250 ms 判据而停止。现有日志缺少采集、解码、提取各阶段耗时，暂不判定根因。

Kimi 2.8 只读取剩余三例的首/末六张 PNG，先固定散列与字节。当前 decoder 和像素提取分开计时；如果既有环境已经安装 Pillow，可比较其 RGB 解码与原 decoder 的完整像素、形状和 dtype 一致性。每张图每个 backend 一次预热、五次计时，保存原始计时和 p50/p95/max；不安装依赖，不修改生产源码，不启动应用、物理、优化器或新采集。

总调度 180 s、2 CPU 数值线程、输出小于 1 MiB。此测量只证明所选 PNG 的性能和一致性；不等于全部格式兼容，也不复现当时的系统负载或实时链路。候选优化需另行源码审查，250 ms 合格线维持不变。
