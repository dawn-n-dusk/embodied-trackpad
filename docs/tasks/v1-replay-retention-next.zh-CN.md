# 保留已有策略能力的下一轮纠错

依据 [FT01 闭环结果](../experiments/2026-11-01-v1-diagonal-finetuning.zh-CN.md)，原策略继续作为基线，候选不晋升。先用保存轨迹诊断，不重新扫描接触参数、不补跑已因预算跳过的第十个条件、不重复同一失败训练。

1. 检查原始数据与执行时的接触/起始状态差异，区分非预期点击变色、画面过期、断触及穿透；视觉模块的外观兼容修改须单独验收，不能把它混作学习收益。
2. Kimi 先实现显式多数据源重放的最小模块，分别调用现有索引校验器，保留每个语料的散列、profile、collection 与原始切分。既有单索引接口继续拒绝混合 profile，不拼接索引绕过约束。旧直线与新斜向语料的同号 target class 必须有语料命名空间。
3. 只从两个语料各自训练部分采样；候选为等比例重放，权重从原策略加载，输入归一化保持不变。验证结果按语料分别报告，预先规定旧任务保留约束及新任务目标，step 0 参与选优。测试集不参与参数或检查点选择。
4. 独立核验采样隔离、确定性与恢复状态后，再接入训练器并签发新的源码/双索引/初始权重绑定合同。原模型和失败候选均保留。预算沿用持续任务上限；本文件本身不申请 GPU，也不启动训练。

优先将工作拆为“语料校验/采样器→训练器接入→冻结小作业→闭环回归”，避免一次实现大脚本后才验收。当前实际模型仍为 50→128→128→400 的 74,640 参数 MLP；预训练 π0.5 全量微调是后续阶段。
