# 四方向斜向教师可行性与纠错数据前置检查

学习策略固定权重的八目标诊断为2/8成功，四次压入中止、两次断触；不能通过重复同一失败策略或放宽1mm门槛改善成绩。下一项有区分力的实验是：在同一物理模型、原生GUI和安全条件下，用已接受的力反馈教师尝试四个短斜向目标，检查这些目标在当前手掌姿态下能否完成。教师成功仅说明可行性与潜在数据来源，不是学习策略成功，也不证明失败唯一来自数据不足。

## 源码模块

Kimi仅给既有近目标教师增加命名task_profile选择：默认near_pointing_v1保持旧行为；新增near_diagonal_v1仅允许seed0–7。未知profile和不合法斜向seed须在创建输出目录、物理环境或应用之前拒绝。run与CLI都验证，实际reset、metadata、summary使用同一个选择。旧字段保持兼容，并明确保存profile以避免把斜向结果当旧轴向任务。

仅修改tools/leap_v1_near_probe.py和tests/test_leap_v1_near_probe.py。物理控制、P1、教师力反馈、3px成功条件、动作与安全阈值、图像时效、离板、进程清理及默认CLI行为全部保持。此模块只运行相关纯静态/stub测试，不启应用、仿真或优化器。最多180秒、2数值线程；独立通过后冻结源码与实际应用/资产散列，再签发运行任务。

## 四回合运行模块

通过源码门槛后，Kimi使用force-governed教师、near_diagonal_v1、seed0/1/2/3各执行一次，即(12,12)、(-12,12)、(-12,-12)、(12,-12)逻辑像素。先核对进程身份和空的新输出目录，不改旧数据、不重试单回合、不增大动作或压力限制。每回合沿用既有教师的120秒墙钟、20秒仿真、120图像和60MiB上限；整批最多10分钟、2数值线程、160MiB。准备/释放、教师特权量均明确记录。第一不安全物理步之后停止该回合全部物理步进，应用仍须退出。若两回合出现同类安全失效，剩余条件记为未运行并回到诊断。

保存全部PNG、动作、逐子步物理记录、触点设备消息、停止原因、完整分母、当前源码/应用/资产身份和退出证据。成功必须满足冻结的初始误差≥10px、连续三张新图像≤3px且误差降低至少50%、实测≥0.5秒离板及进程退出。协调者从原始记录核验，不能以汇总或脚本退出码代替。

本批先保持training_eligible=false；只有完整数据审核后才能进入下一轮训练。不同profile下相同整数target_class不代表同一任务；后续索引需使用(profile, target_class)或等价版本化任务键，保留旧数据和原train/validation/test归属。四个斜向条件已成为开发诊断集，不能在看到结果后重新称为独立未见测试集。后续正式比较按12条件×2次方案另行冻结。

无GPU训练、真实硬件、个人桌面输入或直播由本任务自动启动。屏幕动作链仍为教师/策略→执行器→物理接触→设备模型→隔离GUI。学习actor的输入和控制路径不因教师实验改变。
