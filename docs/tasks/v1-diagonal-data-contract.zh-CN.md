# 对角线数据合同与实施门槛

2026-11-01。本文冻结下一批数据的规则，不表示数据已经采集或训练已经启动。实现与运行由 Kimi 完成，协调者独立验收。

## 划分与身份

采用 `near_diagonal_v1` 原生任务：短距离四方向（各轴 12 px）为类别 0–3，全部训练；对应长距离（各轴 18 px）为类别 4–7，4/6 用于验证、5/7 用于测试。按完整回合划分，不随机拆帧。这是已知开发课程，不是盲测基准。

保留八个方向/距离类别，不能合并成仅“短/长”两类。新索引以采集批次、任务 profile、类别和回合共同标识；数值 seed 可重复，但不能作为跨任务的唯一身份。原轴向数据、划分、索引和模型检查点保持原样。已经用于调参的诊断回合不自动成为训练数据。

## 必须保留的证据

- 请求、采集清单、回合 metadata/summary、审核结果中的任务身份一致。
- 接触模式、完整法向控制/切向限力配置、图像后端与版本一致；0.6 N 与旧 0.8 N 配置不能静默混合。
- 图像采集、保存、解码、特征提取的时间戳以及实际时钟偏移和不确定性保留在元数据。逐帧重算帧龄，并检查包含时钟不确定性的 250 ms 上限；终止画面同样检查。旧数据缺失的时钟信息保留 null 并明确限制，不补造。
- 采集控制源码与数据审核器源码分别绑定。原始轨迹、图片、模型和日志保持校验值；新版审核器不能冒充历史采集源码。
- 模型输入维数保持 50（视觉误差 2 + 关节位置 16 + 速度 16 + 前一控制量 16）。任务/时钟/力控制配置只是元数据，不加入 actor 输入。动作标签继续使用实际执行的 25×16 控制量。

## 按模块验收

1. 分组 helper 已通过 50 项聚焦与回归测试。
2. 接通回合/样本/数据清单中的任务与批次身份，保持旧默认输出兼容。
3. 逐帧时钟与接触配置一致性审核已接通，127项聚焦测试及独立边界检查通过；完整CLI入口仍须单独验收。
4. 接通 CLI 全局采集清单审核与报告，再审核旧版训练读取器的 profile 假设和重复回合判定。当前读取器按旧轴向类别重新分组，不能直接用于对角线数据。
5. 冻结采集源码、配置、预算与前置检查后，采集新的八条件小批完整回合；逐个保留成功、失败与缺失信息。审核索引通过后，才签发小策略训练任务及资源许可。

每个源代码模块通过不等于整个数据管线通过。原始回合继续保持 `training_eligible=false`；独立审核后的训练许可必须绑定确切索引和源码。学习策略仍须在单独冻结的场景上评估，不能将教师的成功算作学习成绩。
