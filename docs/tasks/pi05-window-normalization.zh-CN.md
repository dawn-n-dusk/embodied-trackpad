# 20 ms 窗口归一化：独立数据模块合同

2026-11-02。SuperPod 连接暂不可用时推进本地数据适配；不改动已冻结的 GPU 恢复入口与原生 2 ms 检查点。

## 本模块范围

新增独立 `fit_pi05_window_norm_stats(corpora)`，输入已验证的 `VisualCorpus` 序列，复用 `rows_from_corpus` 与 `assemble_windows`。只处理已收集的索引与标签，不解码图片、不采集数据、不运行物理或优化器。旧 `pi05_normalization.py` 与 `Pi05NativeSample` 接口保持原义。

每个完整训练窗口贡献一次起始行的原始 `actor_input.q_rad16`，以及 25 个 20 ms 绝对关节参考。窗口均匀加权；重叠参考会重复参与统计，这与未来均匀采样窗口的训练目标一致，但不代表更多独立回合。验证／测试窗口不参与拟合，覆盖不足的尾部窗口不参与拟合。

统计采用 float64、总体标准差（ddof=0）与线性插值的 1%／99% 分位数，输出 state/actions 下的 mean/std/q01/q99。常量通道不伪造方差。下游计划保持 OpenPI 的 `(x-q01)/(q99-q01+1e-6)*2-1`，本模块只拟合，不执行归一化或模型输入转换。

## 数据与来源

- 每个输入必须为 `VisualCorpus`；重复 corpus_id 或 index SHA 拒绝，按命名空间组合，不拼接绕过原索引校验。
- 使用原始索引字节读取起始状态并核对完整 SHA；窗口由现有公共接口生成。两次读取若不匹配同一冻结 SHA，则拒绝；不使用私有 `_records`，不调用 `example()`。
- 起始行与窗口的 corpus、SHA、split、episode、frame、first_step_index 逐一匹配，再取 16 维有限 q。动作必须为 25×16 有限粗参考。
- 元数据明确区分原生 dt=0.002、目标 dt=0.02、horizon=25、总长 0.5 s、绝对弧度命令，以及窗口加权方式。记录各语料训练窗口数、总状态／动作数、常量通道及全部训练窗口来源的稳定摘要；不把私人路径放入统计身份。
- 统计结果不得接受为旧 2 ms 原生统计量；后续应用模块必须验证新的格式版本与时间合同。

## 验收与预算

先实现单模块，再补限定测试，随后对两个冻结语料做一次真实数值拟合，保存统计量与起始行／粗动作小型证据供协调者独立复算。预期训练窗口总数 599，动作参考 14,975；以实际核对为准。检查验证集极端值不改变训练统计、重复来源、索引改动、无训练窗口、NaN、数值公式和不解码图片。

每个本地数值批次最多 10 分钟、2 线程；产物最多 16 MiB。无 SSH、GPU、安装、GUI、硬件、采集或直播。公开提交仅包含已审查模块／测试及脱敏记录，原始索引与私有路径仍在忽略目录。
