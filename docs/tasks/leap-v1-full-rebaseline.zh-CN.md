# Kimi 下一阶段：LEAP v1 Full 独立基线

2026-10-31，**准备完成，尚未派发**。依据 [ADR 0007](../decisions/0007-leap-v1-full-and-learning-priorities.zh-CN.md)，用户当前硬件目标为 v1 Full。此合同不是运行授权凭据或已完成实验；实际派发需冻结准确基准提交、文件范围、工作目录和预算。

## 范围与不变量

- 使用成熟的 v1 MJCF/URDF 起点；核对 Full 的 XC330 参数与简化模型、Lite/XL330 示例差异。冻结当前来源提交、许可证和所有资产校验和，旧 Menagerie pin 只作定位线索，不假定最新。
- 保留 v2 的 `leap_sim`、探针与结果不变。v1 使用独立模型 ID、清单、16 通道 actuator order 和校准 ID；复用公共 touch/GUI 接口，不复制整套协议层。
- 文件范围在派发时具体化，候选为 `src/embodied_trackpad/leap_v1/`、v1 工具/必要边界测试、v1 模型清单及独立实验记录；不修改已有历史 ledger 项。
- 通过执行器推进动力学，不能逐帧写 qpos 或移动板面伪造接触。先验证固定掌部工作空间，再决定是否需要腕/臂扩展。
- FSR 标记为未安装，仿真接触力与未来传感器输出分开；不得声称存在真实电流、FSR 或硬件精度。

## 第一段有界验收

建议首个任务只用现有 CPU 运行时，一个进程、最多两线程、下载最多 100 MiB、物理执行累计不超过五分钟，Kimi 调用不超过 15 分钟。无安装、GPU、设备、VM、全局输入或训练。

1. 编译并导出 nq/nv/nu、关节/执行器顺序、限制、惯量、碰撞、指尖与传感器清单。
2. 检查单指屈伸、侧摆、两指可变间距和抬起，记录参考与实际状态、警告、限位和接触，不把编译成功当可用。
3. 保存真实渲染和源码/模型哈希，协调者只读审查；Full 动力学未标定项明确保留 unknown。
4. 通过后另立短任务检查板面接触和持续截图反馈。新的截图应改变后续 motor reference，且动作仍经物理触点到 GUI。

## 后续另行冻结的任务

CPU 通过后才安排 v1 MJWarp/H800 对齐；新远程身份、目录与配额先依据私有政策核验。D1 试采、π0.5 显存/微调、RTC 对照和实体 FSR 都属于独立有界任务，不由本次模型导入自动启动。所有成绩保留完整失败分母，人工纠错与自主回合分开。
