# LEAP v2 下一阶段的执行与验收

基准：`7401ab768625b6e5b91e6bf658fdb9899023f958`。这是已发布、经过 CPU 手部动作检查的完整 LEAP v2 Advanced 模型。以下是已分派给 Kimi 的有界任务，实际结果以实验台账为准；任务分派不代表运行成功。

## 固定触控板接触

在固定手掌和 160 × 110 mm 静止板面上完成一次“悬空—按压—保持—滑动—抬起”。保留 17 个执行器、21 个关节、四组耦合以及当前碰撞设置。教师可在独立状态中求逆运动学；运行中的手只能通过电机参考和动力学演化，不能直接写关节位置或移动板面来取得接触。

触点来自实际接触几何与 `mj_contactForce`，多点接触按正向压力加权聚合。保存原始几何对、接触位置、力和时间；非指尖触碰、板边/背面接触独立记录。坐标与正常力不能来自计划轨迹或合成点击。

预定门槛：初末均连续悬空至少 0.3 秒；同一指尖连续有效接触至少 0.3 秒，接触期间切向移动至少 5 mm；关节限位偏差和耦合误差不超过 0.01 rad，穿透不超过 1 mm，板面压力不超过 5 N，无非有限值、警告或非法控制。设备按压门槛沿用 1 N，释放门槛为 0.6 N，运动通过与按压通过分别判定。

预算：单 CPU 进程、最多两线程、最多 16 个实际候选回合、累计物理执行不超过五分钟。先独立审核接触轨迹，再把 `touch.v1` 送入原生 Mac 测试 GUI，检查实际窗口图像；本阶段不启动数据量产或策略训练。

## H800 后端

使用同一模型、初态、控制序列与 14,000 步长度，比较 CPU 与 MuJoCo Warp。禁止通过删关节、去除碰撞或改变动力学来取得兼容；发现不兼容就保存失败证据。

预算：一个 Slurm 作业、一张 H800、最多八 CPU、最长二十分钟。逐级运行 1、32、128 个世界；只有前面通过、容量足够且剩余时间足够时，才运行 512 个世界。记录真实 GPU、分配、版本、编译开销、完整序列耗时与检查覆盖。重复相同世界只验证后端，不能证明多任务泛化或训练加速。

检查世界 0 的接触/关节，间隔不超过 20 步并包含最后一步；全世界状态至少每 200 步及最后一步检查。采样检查与逐步检查分开表述，无法观察的 GPU 警告标为未知。接触标识使用经先前运行核实的 `contact.geom[]`，不依赖读取后可能未更新的旧字段。

## 后续算法入口

触控板接触和 GUI 图像反馈通过后，才做 D1 动力学示范试采：记录实际动作、接触、图像和成功/失败。首个学习实验应同时包含独立布局测试与重新规划后的闭环执行；优化器更新、训练损失下降、重放教师轨迹和自主成功分别报告。ACT 风格动作块、GRU 基线及长期记忆继续沿用架构 v2，不因目前没有实体设备而改成软件坐标点击。

硬件到位后校准实际电机与指尖参数。外置 Apple Trackpad 可以作为设备，但仍需连接一台 Mac；当前软件工作不要求已有一台完全空闲的 MacBook。
