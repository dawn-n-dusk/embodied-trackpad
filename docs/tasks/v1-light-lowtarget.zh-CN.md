# 轻触教师的较低目标力候选

前置证据：[单回合轻触失败](../experiments/2026-11-01-v1-pointing-light.zh-CN.md)和[原始门控统计](../../experiments/records/v1-pointing-light-stats-20261101.json)。3,000 子步中 902 步 gate=0，均值 0.012987；两层控制器的 common_scale 都为 1，没有记录到关节/周期限幅饱和。末期测量力约 0.897 N，高于 0.8 N 目标。

这说明横向动作被大幅衰减，但没有证明接触力偏高的完整物理原因。下一候选只降低教师目标力，测试是否能给滑动留出空间，不把它当成已验证改进。

## Kimi 实现范围

在现有教师 runner 和其 stub 测试中新增独立 `pointing-light-lowtarget` 模式：法向伺服与切向门控目标均为 0.6 N，切向停止阈值仍为 0.9 N。保留 standard 和原 pointing-light 的 0.8 N 行为。两个所选配置必须进入所有调用点并完整存入 metadata/summary；非法模式组合在输出、环境和应用启动前拒绝。

不改物理求解、接触判据、1 mm 穿透/5 N 物理上限、动作限幅、原生点击 1.0/0.6 N 状态机、目标颜色、像素提取或成功阈值。不向 learned actor 添加教师信息。

## 顺序与停止条件

1. Kimi 实现上述两个文件并运行已有纯 stub 测试，协调者独立审核差异与配置路径。
2. 源码、应用、资源冻结验收后，另发单次 seed 3 对角教师试验；本任务文档不跳过源验收。
3. 单回合预算沿用 120 s 墙钟、20 s 仿真、120 张图、60 MiB、2 CPU 数值线程。只执行一次，不扫描参数、不改失败判据。
4. 独立核验逐步控制、触控消息、最后动作后的截图覆盖、全程压力和释放；失败保留分母。数据保持训练不合格，直到另行数据审核。

没有这次回合的真实证据前，不宣称它改善精度，也不启动新训练。
