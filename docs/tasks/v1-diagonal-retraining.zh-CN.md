# 对角任务第二轮训练

2026-11-01，用户明确要求继续重启训练。本文件冻结下一轮的实施顺序和预算；它不表示优化器已启动，也不替代绑定真实数据索引的执行许可。

目标是改善首个学习策略在对角任务上的2/8结果。已有两个轴向测试通过，终止误差0.874/2.812 px；八个对角测试保留四次压入中止、两次断触。此前的教师诊断不计入模型成绩，也不直接纳入新训练集。

## 新数据和源代码

先完成对角批次审核 CLI 与训练读取器适配，保留旧轴向行为。采集器、审核器和训练器的源码分别记录，不用审核器版本替代历史采集版本。所有输入、输出索引与权重按校验值冻结。

采集新的八个 `near_diagonal_v1` 完整回合：类别0–3为训练，4/6为验证，5/7为测试。这个划分是已知开发课程，不称为盲测基准；同一回合不随机拆帧。完整保留计划数、尝试数、成功、失败与缺失。Kimi可在全部回合通过后，运行已验收的离线审核器生成候选索引，以减少重复派发等待；候选索引仍不可用于训练。协调者独立复核原始数据和索引的时钟、图像、接触、配置、动作因果链与来源后，再签发绑定索引散列的训练许可。

沿用已验收的教师配置：法向目标0.6 N、切向停止阈值0.9 N、Pillow后端。实际版本、完整配置和时钟偏移仍需逐批记录。动作经关节、物理接触、触控设备模型到隔离 GUI，采集不接真实硬件、不向个人桌面输入。

本地采集批次上限10分钟、2个数值线程、8个回合、256 MiB；每回合沿用120秒墙钟、20秒仿真及60 MiB上限，批次上限优先。触及原安全门槛或输出预算立即保留证据并停止，不放宽1 mm穿透和5 N板面力门槛。定位成功仍需连续三张新图像误差≤3 px、较初态降低≥50%，以及实测≥0.5秒离板和应用退出。

## 学习和独立评估

用户进一步明确优先继续使用已有策略。保持首轮74,640参数 MLP、50维输入和25×16动作块，从当前已验收的最佳权重进行全参数微调，不默认随机初始化重训。新数据采用新的训练输出目录，旧权重保留为比较基线。

现有严格断点恢复要求数据和源码完全匹配，因此需要单独的“载入已有权重开始微调”入口。该入口绑定初始化权重散列，保留原输入归一化器、重新建立优化器与采样器，并记录新的数据来源。不能只载入权重后重新拟合归一化器，否则更新前的网络行为也会改变。微调自身的断点续跑仍须严格恢复其优化器、随机数和采样状态。

首个微调候选使用 AdamW：学习率0.0001（首轮的十分之一）、权重衰减0.0001、批量64、梯度裁剪1、种子17、最多500次更新、每100次更新验证。所有网络参数参与更新；原归一化器固定，且它仅由原训练集拟合。先核验更新前的预测与原模型一致，再开始优化。按新验证集选检查点，测试集不用于选模。训练样本不足一个批量或任一必要划分缺失时，不启动优化器。

完整保留随机初始化的旧基线模式和严格许可检查；新增微调模式需要独立的源码测试、初始化来源绑定与执行许可。若对角改善但轴向明显退化，再评估加入经单独审核的旧数据回放，不先把不同接触配置和任务批次静默混合。

申请1张H800、最多30分钟、2个数值线程、无在线仿真环境，且计入现有滚动24小时6 GPU小时预算。通过Slurm实际分配后才运行。记录优化器真实更新、训练退出码、检查点恢复验证、导出数值一致性和资源释放。调度器的COMPLETED本身不能作为训练成功依据。

训练结果通过后，再在隔离GUI中运行冻结检查点的独立闭环评估。先验证新数据划分和原轴向任务；必要的模型比较按12条件×2次规范进行，不重复同一确定性回合增加样本数。汇报成功率、均值、波动、失败原因和终止观测缺失，不能只报最佳个例。
