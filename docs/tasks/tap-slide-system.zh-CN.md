# 点按与滑动：当前完整系统的组成和验收

本页解释用户已确定的本轮工作；硬件/输入/预算见[ADR0010](../decisions/0010-wrist-tap-slide-system.zh-CN.md)。旧pi0.5与自动化不恢复。

## 输入和输出

| 输入 | 含义 | 来源限制 |
|---|---|---|
| 屏幕RGB | 光标、目标、操作结果 | 自有虚拟测试GUI；不控制个人桌面 |
| 腕部RGB | 手指附近板面与接触工作区 | 相机刚性安装于随腕转动的手掌侧；必须实际渲染 |
| 17关节q/dq与近期动作 | 16手指＋1腕部俯仰的状态 | 具名映射；joint顺序与actuator顺序不可混用 |
| 触点、板面xy、模拟法向力 | 是否接触、接触在何处、模拟按压力度 | 显式simulated标识/量程/量化/缺失mask；真实硬件可用性未验证 |

输出是17维关节目标序列。真实物理接触推动虚拟触控板，再由设备更新GUI。模型不得直接写光标坐标或调用点击；GUI坐标真值只给教师/评分器。

## 第一阶段任务

点按是短时接触后离板产生一次点击；点击落入目标才算成功。滑动是单指接触产生相对位移，离板后光标不再移动、不误触。其他手指保持不触板。目标达成、误触、接触丢失、超过力/穿透上限分别记录，失败不从分母删除。

## 实施顺序

1. 结构和相机：独立17关节手模、正确接触参数、可解释的腕部轴与限位、随掌运动的真实图像。
2. 工作姿态和物理专家：自然半曲手型、食指/中指工作区居中、腕低指根高；完成实际落指/短滑动/抬指，保留每个物理步的力/碰撞/时钟。
3. 完整闭环与数据：接触→设备→GUI；同步保存screen/wristRGB、关节状态、动作、传感器输入与独立评分。小批先审核，随后扩大多方向/距离回合。
4. DexWild模型：上游固定版本的视觉编码＋扩散动作策略，适配17维动作和本项目观测；实际统计总参数/可训练参数。完整官方LEAP策略权重尚未找到，不能把视觉初始化叫完整机器人策略微调。
5. 训练与评估：按episode拆分训练/开发/测试，只用训练集拟合归一化；真实更新后保存并恢复模型/优化器/随机状态；同一模型采样动作回到物理闭环，报告独立回合指标。

公开数据用于后续预训练/联合训练时必须保留原相机和动作语义，不能截断机械臂/LEAPv2动作来伪造本机构标签。当前原始公开数据以大分卷发布，不默认全量下载到个人电脑。

## 当前证据边界

2026-11-02：新工作姿态已保存并实际渲染，总览及腕部图像已由协调者查看；P1 priority=1已补上。两个物理回合记录了接触与抬指，峰值板面力约1.66N、穿透约0.432mm。但工作器所写“2/2通过”只表示未触发安全失败：点按接触持续约650ms，超过设备350ms上限；滑动要求5mm，实际仅约0.327mm。因此点按/滑动任务均未验收，不能进入模型训练。腕部图像仍有较多手指遮挡，姿态也需要用户观看确认。详见[独立复核](../../experiments/records/tap-slide-working-contact-review-20261102.json)。

软件设备/GUI已通过修正后的29项独立测试与六项反例复查：过期释放、ID交换、多点转单点不再误触；目标外点击不显示成功；缺失力保留mask；非法输入不会部分修改设备状态。已整合设备/GUI模块。软件测试不代替物理接触。详见[记录](../../experiments/records/tap-slide-device-reviewed-20261102.json)。

前两个Kimi调用超时已保留，未用源码保存或reported代替验收。当前尚无本轮训练数据接受、GPU训练或学习策略成功。后续完成时在本页和账本追加准确结果。

实时调试推流已由浏览器独立验收：总览和腕部640×480双视角、约4fps，页面明确SIM DEBUG / DEMO。此次有效实例截止2026-11-02 18:32:03香港时间；这是带小幅腕部运动的实时物理渲染，不是训练或已学会点按/滑动。详见[直播证据](../../experiments/records/tap-slide-live-accepted-20261102.json)。
