# 下一步：定位 v1 滑动断触，冻结可复现的接触配置

状态：2026-10-31 已派发至现有 Kimi 接触诊断会话，结果待独立审查。本合同接续 2026-10-31 的原始、平滑轨迹、接触柔顺性和反馈教师诊断。它不启动 D1 采集或策略训练。

1. **先定位断触。** 使用已有轨迹定位丢失接触前后各 20 ms，记录几何对、距离、接触法线、法向力、约束状态、指尖位姿/速度与控制量。分别统计“没有几何接触”和“仍有接触但法向力低于阈值”，不能将二者混为一谈。检查位移来自指尖真实运动还是接触点切换。
2. **再做轨迹对照。** 在同一固定手掌、板面和接触配置下，比较现有侧向关节轨迹与保持板面高度的协同关节轨迹。允许离线规划器或隔离的 FK 数据用于求解目标；实际运动始终由 `ctrl → mj_step` 产生，运行中的状态不得被位置写入替代。教师可以使用特权物理状态，必须与部署 actor 分开。
3. **保留原始门槛。** 完整 16 通道，前后各至少 0.3 s 离板、至少 0.3 s 单指有效接触、连续接触内至少 5 mm 滑动、全板正法向力总和不超过 5 N、穿透不超过 1 mm、关节越界不超过 0.01 rad、状态有限且无警告/非预期接触。不得删掉断触采样点来通过。
4. **接触识别与物理模型分别处理。** 如果后续需要设备采样、迟滞或去抖，必须作为独立的虚拟触控板模型变更写入决策记录，保留原始无滤波指标，并专门检查真正抬指时的及时释放和误触率。处理后的连续触摸不得改称原始物理接触连续。
5. **冻结再接入。** 通过后保存场景参数、控制轨迹、代码/资产散列、原始接触和实际渲染；重复验证并做明确的步长对照。然后单独冻结 v1 在线视觉反馈任务，验证屏幕变化确实改变后续关节动作。

派发时限定一个 Kimi 工作树、CPU 两线程、最多六个候选及两个复核周期、累计物理计算不超过 120 s、产物不超过 100 MiB、单次工作调用不超过 600 s。先检查已有进程与产物，禁止重复启动。无安装、GPU 作业、硬件、全局 Mac 输入、训练或私有账户信息发布。协调者负责审查与 Git 集成；本文件本身不是运行回执。
