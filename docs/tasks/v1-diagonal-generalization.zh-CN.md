# 固定权重的斜向目标诊断

当前基线已通过两个轴向近目标。下一阶段检验两个方向同时变化时的闭环行为；保留原权重、P1、成功/安全门槛和全部旧证据。此诊断不改变训练集，也不把看过的诊断样本继续称为永久未见测试集。后续最终评估另行冻结新样本。

第一模块只扩展原生隔离 GUI：新增命名配置 `near_diagonal_v1`，固定偏移依次为 `(12,12),(-12,12),(-12,-12),(12,-12),(18,18),(-18,18),(-18,-18),(18,-18)`，单位为逻辑像素、+x向右/+y向上，按seed%8选取。目标仍为32×32蓝色方框，只在reset设定，不跟随光标。旧default和near_pointing_v1行为不变，非法配置须原子拒绝，actor不能读取特权状态。

Kimi负责三文件实现、既有签名构建及相关原生协议测试。先保存旧已验收应用的完整副本和散列，再构建新应用。只捕获本应用视图，保存两张相反斜向目标的真实PNG及进程退出证据；这些合成协议测试保持training_eligible=false。本模块最多360秒、2数值线程、100MiB新证据；不运行机器人、优化器、GPU或全局桌面输入。

第二模块在新配置和像素定位验收后，单独扩展评估器的命名套件与源码/应用散列绑定。先通过旧两目标合同回归及新套件边界检查，不能为了新增目标放开任意seed/profile/阈值。随后才签发一次性8目标诊断许可：每项仍最多120图像、20秒仿真、120秒墙钟；整批最多10分钟、2数值线程、160MiB。不调参、不重试，保留全部分母。安全监督只停止，不能补救动作。

实际八回合尚未派发。是否补数据、做下一轮全参数小策略训练或准备更复杂模型，以诊断结果决定。训练/评估监视器的后续接入必须显示实际来源和截止时间；不得拿协议截图或历史回放冒充正在训练的机器人。
