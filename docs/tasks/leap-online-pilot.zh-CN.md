# 下一阶段：LEAP 在线视觉闭环与 D1 前置试采

状态：2026-10-31 已准备的执行合同，**尚未派发、尚未运行**。不是后台作业或已采集数据。Kimi 负责实现与运行，协调者负责接口、预算、证据审查和发布。基线包含完整 LEAP v2 Advanced、已接受的 CPU 板面接触和离线原生 GUI 回放；公开提交与实际源码哈希必须在下一次派发时冻结。

## 首个可验收结果

完成短程视觉纠偏：在当前固定掌部可达范围内，手指驱动光标接近一个可见目标；目标或观测发生可控扰动后，后续电机参考随新截图改变。第一步可以使用明确标记的非学习视觉伺服教师，再产生 BC 试采数据，不能把教师称为学得策略。

当前 5 mm 级单次滑动不等于覆盖整块屏幕。先测可达区域、抬指重定位和二维运动；不足时记录失败并提出腕/臂扩展，不移动板面、不瞬移手或光标、不通过改变增益隐藏机械限制。GUI 目标只可在回合 reset 时按种子布置，在线扰动必须作为有日志的环境事件，不能按实时手指位置自动迎合策略。

## 在线接口

1. 每个控制周期从真实截图提取光标/目标的估计与置信度，结合 21 关节状态、上一动作及短历史。运行 actor 不读取 GUI 内部坐标、目标命中或原始接触真值。
2. 输出按清单排列的 17 维电机位置参考，先经过现有限位/控制器，再运行 CPU 物理；接触由同一时刻的几何、力和身份导出，不能由目标位置生成。
3. 持续发送含空接触的单调 `touch.v1`，保存动作→物理→触点→捕获图像的索引。首版候选 20 Hz 控制、30 Hz 图像；报告实测频率、帧龄、延迟和丢帧，不假设达到配置值。
4. 遇到低置信度、陈旧图像、错误应答、限位/力/穿透违规时停止并记录原因。保持按压、滑动、释放和失败的阶段证据。
5. 特权教师可使用机器人几何与仿真真值求解运动，但必须独立于部署 actor 字段；GUI 评分真值只进入独立 evaluator。屏幕估计的坐标和真值采用不同字段名。

## 有界运行与验收

首次派发建议：单 CPU 进程、最多两线程、最多 16 个诊断回合、累计物理执行不超过五分钟；只运行本项目现有原生测试 app。不启动 GPU、训练、全局输入、VM 或实体设备。源码/测试可在独立 worktree 修改，不能改变已验收模型的质量、耦合与碰撞定义来取得通过。

验收包括：正常闭环、可达范围内的目标扰动、延迟/旧帧拒绝、接触中断恢复；每个回合保留完整结果，按预先定义的布局/扰动清单报告分母。比较正常反馈与冻结/打乱反馈时的后续动作和误差，证明截图确实参与控制，不能只靠时间表重放。保存真实像素证据和 motor/reference/actual/contact 对齐关系。

固定手和板接触的数值门槛沿用已验收探针；若现有参数不能达到目标，记录未通过，重新提交具体改动及独立基线，不暗中放宽标准。成功与失败均可保存，但试采资格需经过来源/质量审查。

## 通过后才扩大到学习

- D1 首批 200–500 条短轨迹，按完整回合和布局划分；不把当前 105 帧离线回放复制成数据量。

- 两者使用相同视觉/本体观测、动作界限和数据划分。训练更新次数、损失、教师成功与学生独立闭环成功分别记录。
