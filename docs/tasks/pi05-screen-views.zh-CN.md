# π0.5 原像素局部屏幕视图

2026-11-02 HKT。全屏缩放到 224×224 已发现光标细节损失；先提供独立、可测试的视图准备函数，再单独验收模型输入槽映射。本任务不改变原训练包、归一化、动作时间尺度或现有检查点。

- 输入仅为当前的 800×600 uint8 RGB。保留完整图像，另生成 224×224 原像素裁剪，不做缩放。
- 裁剪中心只由现有像素检测器从当前图像估计的光标确定；不接受 evaluator 坐标、GUI API、标签或未来图像。目标是否检测成功不影响裁剪是否有效。
- 使用图像左上角坐标。原点为 `(floor(col)-112, floor(row)-112)`；越界部分填零，并给出逐像素有效 mask，不在边缘移动裁剪窗口。图像到裁剪的映射可由原点复原。
- 光标丢失、歧义或置信度低于 0.5 时，局部视图无效、置零；保留全图，不沿用旧裁剪。
- 该检测器只适用当前隔离靶场的固定颜色。不能称为通用 Mac 视觉定位，也不能将局部屏幕图冒充腕部相机。
- 测试覆盖像素保持、横纵坐标、四边填充、目标不参与中心选择、失效情况和数组所有权。合成测试图片只验证软件，不加入训练数据。

Kimi 负责实现与局部测试，协调者独立检查并使用已审核的真实图像样本复核。本模块通过不等于已接入 π0.5 多视图输入，更不等于闭环控制精度提高。预训练输入槽语义、模型 mask 和统计分布需要下一项单独合同。

## 实际验收

独立执行新视图和原视觉工具两组测试，共 88 项通过。两张此前审核过的真实 RGB 样本逐点核对通过，局部视图分别保留 116 个光标颜色匹配像素；两图的光标都在初始位置，这不构成跨位置定位或策略泛化验证。合成夹具中的一处越界目标坐标已修正，生产模块未因该测试失败改变。[审查记录](../../experiments/records/pi05-screen-local-view-reviewed-20261102.json)。

下一步是显式定义 full/local 两路屏幕输入到官方 Observation 的映射，并保持缺失腕部相机的事实和 mask。像素有效 mask 与模型注意力 mask 不能混同；在接入前不宣称模型已经获得局部图像。
