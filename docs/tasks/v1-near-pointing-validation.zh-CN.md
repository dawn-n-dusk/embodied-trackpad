# LEAP v1 近目标视觉回合与小策略入口

2026-10-31。执行合同已定义；最小 runner 经源码与负例测试审查、绑定实际源码、资产、配置和二进制散列后，交 Kimi 执行。本文不是已完成回合或训练成绩。

## 第一批：三回合诊断

沿用 P1 参数和完整 16 通道。以 `near_pointing_v1` 的 seed 2、8、11 建立三个 24 px 初态，依次测试 +x、+y、−y。先执行一回合并检查证据；出现安全或基础链路失败时停止余下同配置回合并定位原因。每回合上限 120 个视觉周期、20 s 物理、120 s 墙钟及 60 MiB 证据；整批不超过现有 12 回合、300 s 物理、10 min 墙钟、200 MiB、2 CPU 预算。准备和释放计入所有预算。

图像来自自有窗口。教师可使用仿真 Jacobian；正常 actor 接口不能读取 GUI 状态或从 seed 推导目标。路径为 PNG → 像素误差 → 16 维关节控制 → 2 ms 物理子步 → 实际接触 → touch.v1 → 下一帧。固定准备动作不能计入视觉控制。记录因果动作、本体、原图散列和时间，特权物理真值单独保存。

每个子步检查正法向力总和 ≤5 N、穿透 ≤1 mm、关节越界 ≤0.01 rad、有限状态、无新求解器警告及非预期接触。失败保留首次原始记录。失去视觉或帧过期时停止视觉动作；正常结束需实际抬指并连续至少 0.5 s 无板面接触，软件 stop 不替代释放证据。

近目标指向须同时满足：初态中心误差 ≥10 px、末态 ≤3 px 连续三张新帧、较初态改善 ≥50%。完整回合还须通过物理与释放检查。不能用按钮内部或 target_hits 当精度成功。墙钟周期上限 10 Hz，实测各阶段耗时，不承诺已达到 10 Hz。

## 反馈依赖与数据审核

三回合只提供有限诊断。后续加入对照：相同初始物理状态而目标相反时首个控制应改变；相同本体而替换或冻结截图时动作应改变或拒绝；旧帧和重复 frame_id 不得推进视觉控制。恢复若使用教师真值，须标记并排除于部署 actor 输入。

诊断记录先保持 `training_eligible=false`。独立审核图像与动作对应、逐子步原始接触、时间、数据缺失和停止原因后，另写数据清单标记可用片段，不改写原始证据。失败和恢复片段保留来源，按原因决定是否用于监督。

## 小策略的下一道检查

先用少量完整回合验证训练、独立评估和 checkpoint 恢复。此 GUI 只有 12 种方向与距离组合；seed 与 seed+12 具有相同近目标，不能按 seed 数目冒充独立任务。划分至少按实际方向与距离组合及完整 episode，重复采样同布局只能进入同一组。固定材料和单个 GUI 仍不代表一般电脑操作。

第一候选是读取像素提取结果、本体和上一动作的小 MLP，输出 16 维关节增量；特权 Jacobian、接触真值、GUI 状态和未来帧不得输入学生。这是带手工视觉前端的工程基线。数据和动作闭环有效后，在授权的 1 H800、30 min、最多 64 环境预算内验证真实优化器更新、独立闭环评估及中断恢复。后续预训练 π0.5 仍采用用户确认的全量微调路线。
