# LEAP v1 Full 的可拆换 FSR 指腹方案

2026-10-31，设计状态：**可行性与接口建议，尚未制作、安装、采样或标定**。用户已确定采用 LEAP v1 Full，并询问自行加装 FSR 的可行性。标准 Full BOM 没有指尖 FSR；本文不将它写成已有硬件。[来源清单](../../experiments/records/vla-review-sources-20261031.json)保存本轮厂家文档的检索时间与校验和。

## 推荐构型

可以加装。保留完整四指/16 电机手，先在食指与中指制作两个可拆换的传感指腹，验证后再扩展其它手指；不限制拇指参与后续任务。建议修改末端指腹壳体/盖板，不改电机和主传动。

从触控板到手指骨架的力传递路径：

```text
触控板玻璃
  ↕ 接触
柔顺导电外垫（可更换，负责接触识别与摩擦）
绝缘隔离层＋受控传力压头
平放的 FSR 有效感测区域
刚性承托底座＋适度的侧向导向
LEAP 末端连接件
```

FSR 测的是通过传力结构的载荷，外垫负责让电容触控板识别接触，两者不能互相替代。导电软垫需要实际试验其尺寸、接触斑、导电/电容耦合与摩擦；不能保证随便一块导电硅胶就稳定被 Apple Trackpad 识别。传感器电极与导电外垫应绝缘，不能让外垫直接接到电机电源线上。

重要机械条件：

- FSR 感测区保持平整，传力压头落在有效区域内。不要直接把平面薄膜弯贴在弧形指尖上，再把输出当作法向力。
- 载荷应经过感测区，胶、螺钉或壳体不能形成明显的旁路承力；同时要避免滑动剪切力直接拉扯薄膜和焊接处。
- 外垫/压头尺寸、硬度和壳体预压固定并入校准版本。太软会增加形变和时滞，太硬会使接触斑不稳定。
- 尾线沿手指背侧走线并作应力释放，留关节活动余量；装好后重新验证运动范围和自碰撞。
- 新指腹会改变末端尺寸、质量、摩擦及接触位置；同步更新仿真 collision/site 和校准，不沿用原指尖位置假装几何不变。

## 候选传感器

| 选择 | 适合用途 | 需要注意 |
|---|---|---|
| Interlink FSR 400 系列的合适尺寸款 | 首版低成本接触/按压趋势与释放检测 | 官方系列标称约 0.2–20 N；轻到低于有效范围的电容接触可能已移动光标但传感器尚不明显响应。具体封装尺寸须根据指腹 CAD 决定 |
| Tekscan FlexiForce A201 低量程版 | 更认真地测量低法向力、比较标定结果 | 官方低量程约 4.4 N，厚约 0.203 mm，有效直径 0.375 in≈9.525 mm；需适配机械空间和厂家读出电路。报价与供货本轮未核验 |
| 后续三轴/光学触觉 | 若研究确实需要剪切力、滑移和接触形状 | 增加结构、相机/计算、走线和标定成本，当前不作为第一版必要项 |

厂家重复性/漂移指标有特定载荷、预处理和测量条件，不能直接当作我们低载荷滑动时的精度。ADC 的 16 位也不意味着测力有 16 位有效精度。

## 读出与本体数据如何对齐

FSR 是随力变化的电阻，普通数字 GPIO 无法直接测其阻值。推荐独立 USB 微控制器采样，主机接收数据；不必修改 Dynamixel 固件，也不必把传感器接进其电机总线。

Interlink 类阻性 FSR 可先用 3.3 V 分压读出，再按目标力区间选定参考电阻。FlexiForce 按厂家推荐的激励/放大方案选型，不能假定所有传感器直接共用同一电路。USB 小板可选适当的 RP2040/STM32 等；本轮未固定板卡和针脚。

若选择 ADS1115，官方规格为 **16 位、最高 860 SPS、4 路复用输入**。860 SPS 是转换器总速率，不是每路各 860。两路指腹每路 100–200 Hz 可作为初始设计目标，四路时先以每路 100 Hz 留出切换与通讯余量，实际吞吐、通道时差和滤波延迟仍须量测。需要更高频或同步采样时再更换 ADC。

微控制器保存采样时刻与序号，主机另记接收时刻。每个指尖至少记录：

| 字段 | 含义 |
|---|---|
| `sensor_id / finger_id` | 固定传感器与手指映射 |
| `sequence / sample_time / clock_id` | 原始采样时间与时钟域 |
| `raw_adc` | 原始值，便于重做标定 |
| `normal_force_estimate_n` | 仅在标定有效时提供的法向力估计 |
| `calibration_id` | 包含传感器、压头、外垫、预压和拟合版本 |
| `valid / saturated / stale / disconnected` | 断线、饱和、陈旧数据不能用数值 0 冒充无接触 |

电机的 q、dq、电流和温度保留自己的时间戳；用已估计的时钟映射对齐，不用“同一批收到”假装同时采样。滤波会推迟按下/释放判定，需记录群延迟并单独验证异常释放。

## 标定与验收顺序

1. 先在桌面力标定装置上测试单个指腹，用已知载荷或参考测力计，覆盖接触、轻压和目标工作区间。比如 0、0.1、0.2、0.5、1、2 N 只是待选标定点，不是允许施加到 Mac 上的安全阈值。
2. 多次加载/卸载，分别看非线性、迟滞、零点、长时间保持漂移；在不同接触位置和滑动方向重复。拟合后报告误差，不假定阻值与力线性。
3. 再测试导电指腹在实际触控板上的接触识别、移动、释放和两指辨识。FSR 检出接触、macOS 识别触点、系统判定按压是三个不同事件。
4. 将电流、FSR、视觉、设备行为同时记录，建立本机实际阈值和延迟。当前模拟器的 1 N/0.6 N 按压迟滞只是既有软件配置，不是 Apple 硬件参数。
5. 检查断线/饱和、指腹卡住、持续加载与过温情况下的本地停止/卸载行为；先做有监督短回合，不用一条电流惩罚奖励替代设备约束。

## 对策略的意义与限制

FSR 有助于判断是否接触、是否维持载荷、是否已经卸载，也可帮助发现某一手指没有稳定落板。**单个 FSR 不直接测剪切力、摩擦系数、接触斑和打滑**。打滑可由关节运动、指尖视觉、光标变化及力变化联合推断，但需要单独验证。

首版动作仍为 16 维电机位置参考，电流/速度限制留在独立控制层。XC330 的 Present Current、RAM Goal Current 与 EEPROM Current Limit 是不同概念；不能让策略自由抬高自身上限，或高频写 EEPROM 来实现所谓力控制。

FSR 可先只用于记录和本地监测，待标定通过后再作为 actor 输入。仿真里可以为法向力加入传感器噪声、迟滞、延迟和失效 mask，但域随机化范围应从实际测量收敛。没有 FSR 的旧数据要保留缺失标记，不能混入“零力”标签。加入电流/触觉会改变预训练 VLA 的输入适配与归一化，不能假定原模型自动理解新增数值。

软件视觉闭环可以在硬件加装前继续推进；以后比较相同数据和任务下的视觉＋本体、再加电流、再加 FSR，才知道它是否改善释放、误触和长程成功率。
