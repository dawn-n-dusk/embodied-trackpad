# 触控板实时场景查看器

2026-11-02，按用户本次要求，由 Codex 直接修改场景与网页并亲自操作验收。本次例外仅覆盖该任务；训练、真实硬件、用户输入采集和旧自动化没有恢复。

## 当前画面

本地真实 MuJoCo 仿真持续推进并重新渲染，机器人保持初始关节目标。它是场景预览，不是已学会点按/滑动的策略。没有播放预录视频，也没有为了看起来在运动而添加腕部摆动。页面分别显示每个相机的实际帧新鲜度、当前帧号和仿真时间。

- 触控板局部尺寸保持 160×110 mm；绕世界 Z 旋转 90°，长边横跨食指/中指。接触坐标仍使用触控板局部坐标。
- 掌面朝手指方向上仰 10°。修正了旧实现倾角方向相反的问题。
- 按用户确认的“垂直抬高 5 cm”，手掌参考原点距板面从约 48.0 mm 升至 98.0 mm；腕部原点距板面约 73.0 mm。食指/中指指尖中心的平面中点位于板中心。
- 初始食指/中指实际碰撞网格最低点距板面约 56 mm。10 秒静置检查中，最低间隙分别约 51.201/51.183 mm；无名指/拇指最低间隙约 59.672/64.741 mm。没有触控板接触或穿透，所有仿真 warning 计数为零。这只验证该初始姿态静置，不构成动作成功或完整轨迹安全验收。
- 间隙采用变换后的碰撞网格顶点计算；不再把旋转后的网格包围盒最低点当成真实表面。
- 腕部相机随整只手一同抬高 50 mm，相对于手掌的位置与朝向不变，保持刚性连接到手掌，使用当前仿真安装位置。安装支架、遮挡和实际硬件标定仍待后续确认。背景桌面仅用于显示，不参与碰撞。

## 操作

在总览区域拖动旋转，滚轮或 `＋/−` 缩放，双击或“复位”恢复默认视角；可切换“俯视”“侧视”，也可展开总览。焦点在总览区域时方向键旋转，`R` 复位。窗口变窄后布局自适应；右侧内容超出可用高度时可滚动。

图像绘制在 canvas 上，不会触发浏览器原生图片拖动。相机请求串行发送并合并新输入，旧响应和状态轮询不覆盖正在操作的目标视角。最新修正后的实际拖动验收：向上拖 40 px，仰角参数增加 12°，方位不变；上下方向键采用相同方向。此前滚轮验收将观察距离从 0.353447 m 缩短到 0.277587 m。视角命令不改变机器人关节控制或腕部相机标定。

## 启动与生命周期

使用已安装 MuJoCo、NumPy 和 Pillow 的项目 Python 环境，并按项目 LEAP 资产文档下载和校验固定版本资产后运行：

```bash
PYTHONPATH=src python tools/tap_slide_live_view.py --port 8768
```

浏览器打开 `http://127.0.0.1:8768/`。默认没有截止时间；停止所属进程才结束。电脑休眠或退出运行环境会影响直播，不是系统开机服务。一次只运行一个正式查看器；重启前对照本地 `.local/live/runtime.json` 的 PID、开始时间和实际命令，不能只按端口杀进程。

`--lifetime-s` 仅用于临时测试；当前正式实例未设置该参数。`--detach` 是否能存活取决于启动器对孤儿进程的管理；本次直接从桌面持久运行环境启动，并在后续多次请求中确认存活。macOS 的渲染器必须在同一线程创建、使用和关闭，不能通过新建 POSIX 会话破坏图形上下文。

后端最多 12 fps、800×600，当前浏览器实测约 9–10 fps。只保留最新两张图片，日志上限 8 MiB，监听地址为本机回环。低频网页视频不表示控制器只有相同频率，也不表示仿真时间与墙钟严格一比一。
