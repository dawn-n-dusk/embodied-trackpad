# 模型验证与统计比较规范

2026-11-01：用户要求增加样本量并统计平均误差，同时强调不要因验证过多拖慢训练。两个轴向回合和八个斜向回合保留为功能/泛化诊断，不据此做正式模型排名。默认比较预算改为24回合；90回合仅为可选扩展。新的目标套件与统计器尚未实现，以下是前瞻性合同。

## 按阶段分配时间

- 开发诊断：先覆盖至多8个不同条件，定位方向、接触及运行错误；同类故障明确时先修复，不为凑重复次数重跑失败配置。
- 常规模型比较：12个冻结目标，每个2次独立重置，共24回合。优先看完整成功率、平均误差和波动，不能只看最好的一次。
- 阶段性验证：仅在候选已通过诊断、差异仍不稳定或需要发布更可靠结论时，才按预先冻结的扩展顺序增加到30条件×3次、最多90回合。无需每次修改模型都执行。

当前八回合实际运行批次约58秒，八个回合自身墙钟之和约47秒；包含Kimi准备、启动错误修正和报告的调用为310.6秒。该测量不含评估器开发及协调者独立验收，不能直接承诺未来24或90回合的总交付时间。首批结束后用实际吞吐估算余下成本，正常比较每模型累计本地运行上限10分钟；不够则保留不完整结果，优先推进修正。

## 样本与重复

每个模型默认12个固定目标条件，每个条件2次独立重置，共24回合。24和可选90都是工程预算，不是经过功效分析证明充分的样本量。条件、种子、运行顺序、模型检查点和停止规则在首个模型执行前冻结，所有模型使用相同条件。每个回合独立保存，重复失败也保留，不能用补跑成功覆盖失败。

第一版目标候选：半径14、22、30逻辑像素，常规比较取角度7°、115°、187°、295°，共12种；可选扩展加入43°、79°、151°、223°、259°、331°，形成30种并补足每种3次。角度按+x向右、+y向上定义。目标偏移取三位小数后冻结到命名清单。该候选不与原轴向/斜向固定偏移重合，但仍是固定手掌姿态的近距离任务；经可达性与图像提取检查后才能锁定版本，不能边看模型成绩边改目标。故障修复后的新版本与原版本分开记录。

每次独立重置目前主要检查执行时延、采样和运行噪声；确定性仿真中重复完全相同输入不等于新增独立场景。不能把回合数、几千帧或多次重复当成相同数量的完全独立任务。后续摩擦、接触初态、视觉噪声和延迟扰动另建受控场景族，不混入当前结果。模型参数仅按训练/验证集选取；开发诊断集和最终保留测试集分开。

## 汇总与失败

主结果是全部计划回合的成功率，以及成功/失败/安全中止/初始化失败/资源中止/未运行的完整分母。维持原初始误差、连续三张新图像≤3px、误差降低至少50%、实测安全离板及应用退出要求。平均误差不能代替成功率和安全指标。

每回合保存初始误差、完整误差轨迹、最后一次有效画面误差、是否取得动作结束后的终止画面、终止画面误差（有则记录）、最后三帧均值、持续时间、动作数和停止原因。按回合汇总后，先在同一目标条件内平均重复回合，再对条件等权平均，避免长轨迹或某一条件多跑几次获得更高权重。不完整条件必须标明实际重复数和覆盖率。

报告平均值、样本标准差、中位数、P90、有效误差样本数/全部计划样本数。失败回合只要有有效图像也进入对应的观测误差统计；没有终止图像的安全中止不能用前一张图冒充终止误差，更不能填0或悄悄删除。终止误差缺失时明确覆盖率，并同时报告全部回合的失败率。仅成功回合的平均误差可作为额外分析，必须标明条件，不能作为唯一排名依据。

以目标条件为簇进行95%置信区间估计：自举抽取条件，保留各自重复；不对连续帧独立抽样。模型比较使用同条件配对差值和配对成功率，报告差值区间，避免只看两个均值的小差异。小样本区间仅作不确定性提示。若扩样由已观察成绩触发，须披露选择过程；探索性结果不能冒充无选择偏差的正式显著性结论，也不能反复查看结果直到显著。

## 可比性与预算

固定物理模型、GUI版本、像素提取/输入白名单、控制频率与动作限制、回合停止规则和允许的准备/释放脚本。教师与学习策略分开统计；不同输入信息或安全补救能力的模型不可冒充同条件比较。实际延迟、图像失效和资源中止单独报告。

仍通过Kimi运行，协调者验收。每批最多8回合、10分钟、2数值线程、160MiB；每回合沿用已审核的120秒墙钟、20秒仿真、120动作图像和60MiB上限。常规比较每模型累计最多24回合、10分钟实际本地运行、480MiB新证据。可选90回合扩展累计最多30分钟和1.5GiB，仅在明确记录扩展理由及前置条件后派发。以上不含源码实现和离线验收，须分别记录。

前瞻性停止规则：任何同一安全失效类别在不同回合累计出现2次，或前8回合有4次以上同类策略失败，暂停该候选余下回合并先诊断。保留所有失败及未运行项，未运行不能伪称已失败或从计划分母删除；只报告完成回合成功率、计划完成度和停止原因，不把提前中止的候选与完整24回合结果直接排名。这些新规则不追溯改变已冻结八斜向诊断。无新GPU训练、真实硬件或个人桌面输入授权由本规范产生。

统计器需要纯离线测试：不等长轨迹的等权处理、重复条件、缺失终止帧、失败分母、配对差值和按条件自举可重现性。此统计实现任务与新目标生成任务分开，先审核再签发运行许可。
