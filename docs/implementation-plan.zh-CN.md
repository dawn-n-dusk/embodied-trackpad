用户已授权使用既有 SuperPOD/H800，实际执行须遵守 Slurm 分配；当前未预留 GPU 或启动训练。既有 NexArm、Jetson、D455、串口和机器人服务不属于本项目实施范围。

协调者负责设计、任务拆解、预算、只读审查/观看验收、报告与 Git 集成；Kimi 使用 `kimi-handoff` 技能和显式 session 完成有边界的实现与实验。用户进一步明确：环境安装、虚拟机/服务器部署、运行、训练及推流等实操也由 Kimi 完成。超时后保存检查点并重新切分委派，不由协调者自行接管。不要为 runner 的 Git 基线把整个现有未提交工作区提交。

**共同约束**

- 主机构候选为 7 轴固定基座机械臂与完整 Allegro 四指手，执行器全部可用；二指简化对照使用独立关节和可变相对位置的独立模型。Shadow 五指为后续形态扩展。
- 每个 Mac 输入须经过机器人运动、动力学、触点与设备行为。上层输出视觉目标，低层输出执行器参考；桥接不接受策略任意坐标点击或应用内部命令。
- actor 仅使用明确的视觉/本体/历史观测。DOM、辅助功能树、系统光标真值、GUI 内部状态和评分隔离到 teacher/critic/evaluator；新增传感器明确未来硬件对应性。
- 机械能力、训练 GUI 手势、Mac 合成鼠标/滚动、Mac 原生多点触控分别验收。完整手可改变指距不等于 Mac 原生捏合通路已完成。
- 独立目录、服务、数据与资源记录；不得修改无关训练或占用真实机器人设备。拇指/食指禁用实验在主要训练评估后才作为可选扩展。

**包 0：协议、机构与 CPU 参考**

实现 v2 的 EpisodeConfig、FramePacket、TaskContext、SemanticGoal、MotorIntent、MotorObservation、ActionChunk、AttemptOutcome、MemoryDelta 的 schema/样例。规范时钟域、单位、坐标、目标有效期、动作有效 mask 与版本。图像走原生视觉接口，高频运动数据走张量。

编译组合模型，导出 joint_order、actuator_order、控制范围、安装变换和碰撞清单；验证两指落板、指距变化、腕部可达、误触和板边重定位。CPU 回放必须经过动力学。

验收：模型清单与动作形状一致；非法/过期/错版本/越界消息不执行；零动作不被错误标为无效。只验收协议与物理参考，不称为策略成功。

**包 1：H800 MuJoCo Warp**

在实际分配的单 H800 上锁定 MuJoCo/MJWarp/Warp/PyTorch 版本，验收驱动、接触和控制。CPU 与 GPU 执行相同参考轨迹，检查数值、接触/约束及 GUI 结果。批量从 1/32/128/512 逐级测试，记录编译/预热、稳态、显存、接触缓冲区与溢出、物理和完整 GUI 吞吐。

渲染单独测试；定位 GUI、图像复制、推理或物理瓶颈后再扩卡。安装包存在、作业提交成功或纯物理吞吐高均不代表端到端环境通过。

**包 2：动态 GUI、设备与真实 Mac 桥接**

实现可重置、真正响应动作的 GUI；录像不作为交互环境。触控板维护触点身份、接触/抬起、按压保持、相对增益、滚动和重定位；使用各环境明确时钟。

Mac 从独立测试窗口与可审查事件链路开始，按已有授权范围运行。屏幕图像包含光标，记录采集/接收时间、尺寸和缩放；缺失系统权限时报告具体项，由用户在系统界面授权，不改 TCC 数据库。

输入有序号、有效期与来源轨迹；用户接管、连接失效或焦点异常时停止并按设备状态释放。验收真实画面效果及延迟，不以 API 返回值判断任务成功。原生捏合/旋转未验收时单独列为待解决项。

**包 3：教师数据与运动策略**

教师可以读训练真值，但手指轨迹须经 IK、执行器、动力学、触点与 GUI 实际执行；保存失败和纠正。真实 Mac 数据优先来自遥操作仿真手；直接人类鼠标日志不可伪装成关节示范。

ACT 风格候选初始 20 Hz、H=8、每步重规划；比较无集成与带目标/阶段有效性过滤的时间集成。界面变化或策略阶段不兼容时取消旧块。完整手与二指拥有各自控制映射和动作标签。

BC→DAgger/纠错为主线，CNN+GRU 单步策略为公平对照。ACT 集成后动作不可直接套普通单步高斯 PPO。需要 RL 时另交 residual 或 chunk RL 的概率/执行语义设计；不继承 v1 的统一 PPO 参数。

验收未见目标、增益、初态和延迟下的闭环纠偏，记录点击/释放时机、成功、失败与平滑性。

**包 4：新 VLM 与多尺度记忆**

主候选 Qwen3.8-27B，快速对照 Qwen3.5-9B/Qwen3-VL-8B；revision 见 v2。先核对运行时和基线，再用相同数据划分比较 LoRA/全量微调。27B 全量以 8×H800 分片为候选资源，实际验收显存、激活和序列长度。

实现近期视觉历史、长期语义状态与可检索证据；区分 planned/attempted/observed_success/uncertain。记忆训练保持时间因果，纳入模型自产记忆的错误与纠正，不能从动作请求自动生成成功事实。

规划与界面执行可复用权重，但上下文、频率和完成判断分开。持续屏幕流供运动和认知层使用；异步输出检查观测/目标版本，快速控制不等待跨集群逐帧推理。

验收定位、结构化输出、记忆依赖、恢复与延迟分位数；保留无记忆/文本/视觉/混合消融，不用模型卡榜单代替本任务结果。

**包 5：连续长程任务与机构比较**

一次任务指令、依赖操作、无人工逐步提示及子任务重置；先几分钟，再逐级测试 10–20 分钟。设计离屏信息、不同历史同一画面、计数和错误恢复任务，不用等待凑时长。

放大光标作为受控配置，保存大小/分辨率/缩放。运动尝试结束、可见子目标成功、全任务成功分别记录；独立评分真值不回传 actor。按任务、布局、文件集合和整轨迹隔离训练测试。

提供完整评估清单、成功/失败视频、人工介入、误操作、重复/遗漏、恢复、延迟和资源；教师/纠正/自主结果分别统计。比较完整手与独立可变指距二指，保留各自硬件能力边界。
