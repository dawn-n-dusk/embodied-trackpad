# ADR 0005：选定 LEAP v1 Full，集中验证决策与训练方法

> 后续更新：[ADR 0006](0006-latest-leap-and-hardware-readiness.zh-CN.md)按用户新的“最新模型、最高配置”要求，将当前目标改为 LEAP v2 Advanced。本页保留前一轮决策，不再作为 v1 接入授权。

日期：2026-10-31，Asia/Hong_Kong。状态：**设计决策已确定；模型接入和硬件采购未完成**。本决策更新架构 v2 的机构选型，不改变视觉闭环、执行器动作空间、数据来源与验收边界。

用户最新优先级是：价格适中，尽量可扩展到 Unitree G1 或 H2 Plus；若没有合适组合，优先选资源成熟、易仿真和设计的手，把主要研究投入决策与训练方法。已有候选没有被本轮证明同时具备适中报价、所需动作空间、现成 MuJoCo 路径和精确 G1/H2 组合支持，因此采用用户允许的仿真资源优先路线。

## 选择

**选 LEAP v1 Full 作为唯一的新主研究目标。** 采用完整四指、16 主动关节构型，保留独立手指运动和可变指距；不启用禁用拇指/食指的主任务约束。

- 官方组装价约 US$2,200，按本轮已有参考汇率约人民币 1.46 万元；这不是精确 Full 套件的含税到手报价，电机版本、左右手、附件和交付需在采购前明确。本轮没有采购或联系供应商。
- 使用已有左右手 Menagerie MJCF 作为构型与动力学起点，参考 Playground 的任务/控制实现，减少从 URDF 开始移植的工作。
- Full 的 XC330 与 Playground README 的 XL330 不同；简化模型与默认增益不是已校准的 Full 数字孪生。复用资产后仍需核验惯量、驱动、碰撞及触控板滑动接触。
- 将 Tesollo、Revo3、Shadow 等退出本阶段并行主线。已有 Allegro V3 场景继续作运行/回归参考，直到 LEAP 通过接入验收；旧 H800 结果不能转移归属为 LEAP 成绩。

当前选择指向一个模型目标，并不要求立即更换已运行的所有服务。接入通过后冻结一个模型、控制器与数据版本，再比较学习方法，避免硬件变化与算法变化同时影响结论。

## G1 与 H2 扩展

LEAP 没有本轮确认的 G1/H2 官方即插即用组合。后续需设计法兰/安装座，核对手与转接件的质量、重心和惯量，处理供电、线束、计算平台与驱动。上层任务/记忆接口保留通用性；更换本体或手后，低层运动策略仍需重新标定、训练或微调。

若后来把“必须立即采用 G1 原厂支持组合”设为硬条件，优先重新评估 **Inspire RH56DFX**，并保留 **Revo2** 为轻量备选。两者有明确 G1 支持，但持续贴面变距等能力须实测，不能仅凭六个主动自由度判断不能捏合。

“H2 Plus”目前按渠道中的 H2 EDU PLUS 配置理解；官网 H2/H2 EDU 与经销商细分配置不是同一证据层次，最终整机 SKU 和末端接口待实际选本体时确定。此项不阻塞当前研究。

## 本阶段研究重点

| 研究问题 | 方法与对照 | 需要的结果证据 |
|---|---|---|
| 持续屏幕反馈如何改善动作执行与恢复 | 短动作块滚动重规划，与单步策略、较长开环执行作同任务对照 | 成功率、过冲/误触、失败恢复、延迟；动作必须实际经过动力学和触点 |
| 任务规划何时介入运动执行 | 事件触发重规划，对照固定频率调用；统一模型与调用预算 | 完成率、模型调用成本、停顿时间、失败升级效果 |
| 长程记忆是否保存并正确使用历史信息 | 带证据的事件/语义记忆，对照无记忆与简单摘要 | 延迟信息依赖、遗漏/重复、错误成功记忆及恢复；不能仅用运行时长证明记忆能力 |

运动学习仍按 BC → DAgger/纠错的既定主线，依据失败原因决定是否引入 RL。暂不展开多品牌手对比、整个人形平衡或步行。两指简化机构、跨手迁移是主结果成立后的对照，不先扩成多条实现主线。

手部工程仍需达到基本可达性、抬指/释放、轻触与稳定滑动要求，否则硬件/仿真缺陷会掩盖算法效果。它是形成可信训练环境的必要条件，但不作为本阶段研究创新的中心。
