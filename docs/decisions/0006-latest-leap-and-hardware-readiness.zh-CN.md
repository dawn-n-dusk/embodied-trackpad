# ADR 0006：最新高配 LEAP 与硬件到位前的软件主线

日期：2026-10-31，Asia/Hong_Kong。用户最新指示取代 ADR 0005 的 v1 固定选型：采用能找到的最新公开模型和最高配置，先推进仿真与算法；未来可能提供自制 LEAP 手、MacBook 或独立 Apple Trackpad。

## 当前目标

选 **LEAP Hand v2 Advanced 完整五指构型**，保留全部 **17 个电机控制通道、21 个运动关节和两个主动掌部关节**。Low-cost 四指八电机版不作为此次高配目标。硬件材料目标包含 Advanced 金属配置，但公开 URDF 未证明是经过校准的金属版；目前模拟的是公开 Advanced 几何与有明确记录的动力学近似。

官方可下载资产来自 `leap-hand/LEAP_Hand_V2_Adv_API`，本轮解析到的默认分支提交为 `a0936196e8fa0bcefff045d6fc02523d6da591f2`。官网也提供左右手 URDF ZIP。模型没有原生 MJCF，需要转换与控制映射。本轮没有因 v1 的 Menagerie 入口方便而回退。

“最新”按硬件系列和实际可用资产判断，不按不同仓库最后提交日期简单排序。来源提交、下载时间、文件哈希与本地变换均冻结；后续新版作为新实验版本，不自动替换已采集数据的模型。

## 本轮发现的资产差异

- GitHub 两侧 URDF 各有 21 个转动关节。右手缺少 PIP/DIP mimic；左手含四条 mimic，其中中指条目引用了食指。四根非拇指的 PIP/DIP 由腱耦合，不能增加成 21 个独立电机。
- 初始刚体模型可显式采用每指 PIP=DIP 的耦合近似，保留修正记录。该近似不代表已经模拟软指段、腱松弛、迟滞或接触后的形变。
- GitHub URDF 包含十个用于指端标记的额外 link，各带 0.1 kg 惯量；与官网 ZIP 相比恰好多 1 kg。标记应作为无额外质量的 site 保留位姿，不能把标记惯量当成真实手重。
- 官网 CAD 页面提示金属打印版本可能有 forward MCP 约 10–15° 间隙。金属材料不自动意味着更高精度；实际制作工艺和间隙进入后续标定。
- 嵌套软件 LICENSE 为 Apache-2.0，CAD 请求页另列 CC BY-NC-SA。初次公开项目只分发本项目编写的下载/适配逻辑、清单和结果，网格保留在忽略的下载目录；逐项保留来源和许可，不重新标注上游资产许可。

这些是读源发现和接入要求；实际实现、运行与未通过项以 STATUS.md 和独立实验记录为准。旧 Allegro GPU 结果仍属于 Allegro。

## 不等待实体设备的软件路径

1. Kimi 导入并实际运行 Advanced 模型，核验执行器、耦合、动力学和可观察的动作。
2. 接入触控板平面与接触到设备行为的转换，验证按下、保持、释放、滑动与两指变距；再把真实接触送入可重置 GUI。没有 GUI 结果的手指动作只能算动力学诊断。
3. 从完整动作链生成带状态、动作、触点、屏幕与结果的试采数据，检查来源和时序后开始小规模 BC/动作块训练与独立闭环评估。
4. 短操作成立后再比较事件触发规划、纠错、长程记忆；不以占位数据、优化器能执行或重放教师动作冒充自主任务成功。

完整手能力与 Mac 原生手势分开验收。运动层持续输出执行器参考，屏幕图像关闭反馈环；不能因缺硬件就让 actor 直接点击软件坐标。

## 为未来硬件保留的接口

| 配置 | 现在固定的接口 | 到位后需要补齐 |
|---|---|---|
| LEAP v2 Advanced / 实际自制版本 | 模型 ID、关节与电机清单、耦合关系、单位、动作范围、状态与时戳 | 精确 BOM、传动方向/零位、限位、速度/电流能力、延迟、质量/惯量、间隙、指腹摩擦与接触 |
| MacBook 内置触控板 | 设备坐标/尺寸/增益/手势、屏幕帧与校准 ID | 实际触控区域、系统设置、导电指腹识别、操作时延、原生多点手势 |
| 独立 Apple Trackpad | 同一设备行为与屏幕观测接口 | 实际型号/连接方式、安装位置与高度；仍需连接一台运行 GUI 的 Mac，触控板本身不提供屏幕 |

不要求现在有一台完全闲置 MacBook。现有受限原生 GUI 和已授权的 M5/虚拟机路径可继续用于软件验证；外置触控板到位后，其输入隔离及原生多点路径仍需按实际连接验证，不能假定虚拟机天然接收所有手势。

`ActionChunk` 的宽度按 `actuator_order` 与布局哈希确定。21 个关节不是 21 维电机指令；若组合 7 轴臂与 17 电机手，预期动作宽度为 24，仍以编译与映射清单为准。不同手即使动作维数相同也不能复制关节向量或直接沿用策略权重。

目标是提前做好可配置的软件、记录和标定入口，让硬件到位后从短链路校验与策略适配开始。真实自制硬件的直接部署效果需实验确认；本决策不作零样本迁移或即插即用承诺。
