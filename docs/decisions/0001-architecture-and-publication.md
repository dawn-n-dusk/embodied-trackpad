# ADR 0001: Architecture and public development record

Date: 2026-10-30. Status: accepted for implementation.

The user accepted architecture v2 and authorized a public GitHub project, ongoing documentation, and recorded development. The coordinator owns the framework and review; Kimi owns concrete implementation.

Use an articulated four-finger primary hand, preserve independently articulated two-finger comparison, and separate task/GUI reasoning from continuous motor control. Use CPU MuJoCo reference plus a validated GPU path, short action chunks, and evidence-backed multi-scale memory. Robot dynamics and touch events remain the only route from policy actions to GUI inputs.

Create a dedicated repository for this project. Existing private robot-control work remains separate. Publish project-authored designs and code plus reviewed evidence summaries; do not export raw sessions, credentials, account/host configuration, or unrelated project archives.

Every meaningful step is represented by a source/result commit and an append-only experiment/development record. Publication does not turn proposed results into measured results.
