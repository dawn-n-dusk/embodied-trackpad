# ADR 0009：小 MLP 保留作对照，推进预训练视觉动作模型

2026-11-01。用户指出 74,640 参数 MLP 过小，要求考虑深层 CNN 和现代机器人动作头。本决策修正实施优先级，落实 ADR 0008 已确认的完整预训练 π0.5 全量微调路线。具体对照配置尚未实施或训练。

## 当前模型的真实边界

网络为 50→128→128→400，约 0.30 MB FP32 权重。输入只有二维视觉目标误差、16 维 q、16 维 dq、16 维上一控制。它不直接看图，没有历史或语言输入；手工颜色提取已把截图压缩成两个数。输出为 25×16 动作增量，每步对应当前 2 ms 物理 tick，整个块仅覆盖 50 ms。这不是视觉 ACT，也不是 VLA。

小模型已经验证执行器→动力学→触点→GUI 的链路，暴露数据和执行问题。它保留为固定工程对照，不再要求先把它调到高成功率，才允许更合适的模型进入项目。FT01 失败及原权重保留，暂停扩大同类 MLP 扫参。

## 实施路线

1. **主线：完整机器人预训练 π0.5，全量微调视觉语言主干及 Flow Matching 动作专家。** 保留机器人预训练能力，不仅复制一个随机初始化的动作头。既有微调报告约 3.35B 参数是其特定配置参考，实际总参数、可训练参数与显存需按加载配置统计。LEAP 16 关节需要明确动作映射、padding 和有效 mask。
2. **对照：预训练 CNN＋时序 Transformer＋ACT 风格动作块。** ResNet-18/34 级视觉编码器、适度宽度时序模块是初始候选；约 20–60M 仅为设计预算，不是实测参数量。直接输入截图、短历史、本体和目标条件。采用 ACT/CVAE 时准确实现 latent 的训练与推理语义；普通回归 Transformer 不改名 ACT。
3. GR00T 的 DiT/Flow 与 LingBot 的未来特征辅助任务留作后续受控比较；当前不同时复制 MoE、双教师与多本体预训练。

主线和对照共享数据适配层。ACT 的实现不作为 π0.5 接入的前置门槛；也不把另一个从零初始化的几十兆参数网络替代已选的预训练路线。

## 输入、时间与数据合同

- 真实 RGB 全图保留布局；局部裁剪保留光标精度，裁剪只能由 actor 可见信息产生，不能用 evaluator 坐标。必须检查降采样后的光标尺寸，不默认 224×224 足够。
- 时序对照候选使用过去 4–8 个带时间戳观测，不跨 episode/reset。π0.5 是否支持所需历史输入以实际代码为准，不假定默认具备长期记忆。FSR/电流缺失 mask 保留，仿真力不冒充已有传感器。
- 正式策略动作周期与物理步长分开定义。初步候选为 20 ms 控制参考、10 个 2 ms 物理子步；25–50 个参考对应 0.5–1 s。先验收标签重采样、插值和执行语义，再运行。执行短前缀后重规划，RTC 参数由实际延迟决定，不承诺 Orin 100 Hz 神经推理。
- 两个已审核语料合计 20 段教师回合、1,224 个动作块，只足以做训练接口 smoke，不能支持 GUI 逻辑泛化结论。后续覆盖布局、目标、颜色、光标外观、接触阶段与恢复，按完整回合/布局隔离评估。
- 微调重放旧任务训练数据、分别报告任务验证成绩，防止遗忘；既有单索引校验器仍拒绝混合 profile。通过显式多语料适配组合数据，不拼接绕过检查。
- 短历史、动作块与长期任务记忆不同。多步目标、完成条件及历史依赖另设上层与长程评估，不能由 CNN 或 Flow 结构直接宣称已实现。

Kimi 先核对官方实现/权重入口、现有图像证据、16 通道适配和实际依赖，返回最小代码任务。随后冻结小规模前向、反向、梯度、保存/恢复检查，再推进全量微调。继续沿用已授权工作，不重复请求许可；算力预算、数据许可与具体分配仍须核验。
