# ADR 0012：并行比较世界模型与 BC、纠错、PPO

日期：2026-11-18（香港时间）。状态：用户已授权实施和运行；当前训练结果待产生与验收。

用户先要求尝试 BC 训练并允许大量资源，随后明确同时尝试 world model 与 BC＋纠错＋PPO。本决定更新 ADR 0011 中世界模型留待后续、当前仅整理视频和搭场景的范围。机器人仍为 SharpaWave 右手与完整 7 轴机械臂，暂用 Panda 仿真模型；采购型号尚未确定。

两条路线共用物理环境、初始数据、动作接口和冻结评测。路线 A 保留 BC、BC＋学生状态纠错、BC＋纠错＋PPO 三个独立检查点。路线 B 学习动作条件下的潜在动力学、奖励与终止，并通过模型预测控制或想象训练的策略实际选择机器人动作。仅生成预测视频不计为控制路线完成。

## 公共接口

策略输入：屏幕相机 RGB、腕部相机 RGB、29 个关节的位置与速度，以及明示的模拟接触信号和有效性掩码。策略不接收 GUI 内部光标或目标坐标、专家阶段和专家动作。奖励、教师与评测允许使用特权状态，但与策略输入分开。

策略输出：29 维归一化关节位置增量，经关节和速度限制后作为动力学控制目标。禁止步间重写实际关节位置、直接设定光标或调用点击接口。初始控制频率 15 Hz、物理频率 120 Hz；所有训练和评测必须记录实际频率与执行参考。

BC 路线首版采用有图像编码和时间状态的单步连续动作策略，使纠错和 PPO 共用动作语义。若后续改成动作块，必须重新处理概率、执行时序和 PPO 比率，不能直接套用单步实现。

## 数据与评测

原有 14 组视频素材属于参考材料。进入机器人 BC 需要经过动作估计、重定向和实际仿真执行验证。脚本几何专家可以补充机器人示范，来源必须标为仿真专家，不能称为视频监督或已学会操作。

纠错必须由真实学生检查点 roll-in 后，在学生到达的状态上生成专家标签；增加一批独立专家轨迹不叫 DAgger。世界模型可以学习有效的失败轨迹，但 BC 入集资格、来源和额外环境交互量分别记录。相邻帧、重采样和动作窗口不计为独立示范。

纠错依据 [DAgger 原论文](https://arxiv.org/abs/1011.0686) 的学生状态分布问题设计；策略优化依据 [PPO 原论文](https://arxiv.org/abs/1707.06347)，保存行为策略的动作概率和真实交互批次，不把离线专家回归损失称为 PPO 更新。

训练、验证、测试按完整 episode 和配置组隔离。固定测试包含未见目标，以及安装位置、相机关系、光标增益变化。各阶段报告完整成功率及分母、误点击、接触中断、抬指失败、任务耗时、实际采样量和 GPU 时间。预测损失、离线动作误差与自主任务成功分开。

## 首轮资源与停止条件

首轮上限为一台 RTX 工作站最多 5 张卡、至 2026-11-18 06:50 UTC，按采集与模型准备程度使用，不预先将空闲显存称为资源预留。初始数据目标 1024 条唯一完整成功示范，最多 2048 次专家尝试；BC 最多 20,000 次更新每 seed，最多 256 次学生纠错 roll-in，PPO 最多 1,000,000 条真实仿真转移每 seed；世界模型最多 20,000 次更新每 seed及相同真实交互上限。最多 3 个训练 seed。固定阶段评测各 100 回合。以上均为上限或目标，不是已完成数。

实际环境仍是 Isaac Sim；原场景使用 CPU PhysX 和 RTX 渲染，批量化和 GPU 物理性能必须重新实测。H800 可承担模型计算，但不把它当作已验证的 RTX 渲染环境。任何集群 GPU 工作均需本人 Slurm 分配。依赖安装隔离，不改其他项目运行环境；资源压力或截止时间触发本任务保存检查点并退出。

当前共同前置工作是将几何间隙接触代理替换为实际 PhysX 接触报告，并完成落指、滑动、抬起和点击链。新版未验收前，不用代理成功或 mock 数组启动正式策略训练。可并行实现训练器与接触环境。
