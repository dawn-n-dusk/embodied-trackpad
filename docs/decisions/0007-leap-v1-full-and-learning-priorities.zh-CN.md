# ADR 0007：用户确认 LEAP v1 Full，更新学习实验优先级

日期：2026-10-31。**硬件目标及中后期按效果决定是否使用 RL 的路线已由用户确认；具体模型与实验配置为本轮证据评审后的建议，尚未实施或验收。** 本决策取代 ADR 0006 的“持续使用最新 v2”选型规则，不覆盖其历史实验结果。

## 当前硬件目标

采用 **LEAP Hand v1 Full，高配四指、16 主动关节，XC330-M288-T 电机**。不是 v1 Lite，也不是五指 17 电机的 v2 Advanced。标准版本没有指尖 FSR；自加装可拆换 FSR 指腹纳入设计，先验证食指/中指，再按收益扩展。

当前仓库已经运行的 `leap_sim`、CPU 接触探针、H800 512-world 结果和 Mac 离线触点回放属于 **v2**。它们保留为工具链与回归证据；v1 的模型、驱动近似、16 维控制映射、接触、CPU/GPU 与 GUI 链路都需独立验收。不得将 v2 的 17 维控制截断一维来冒充 v1。

## 研究优先级

1. 复用 MuJoCo CPU/MJWarp 和原生受限 GUI 的可用基础，完成 v1 新基线与在线视觉反馈。当前没有换用 Isaac Lab 的必要证据。
2. 小型视觉/本体策略作为工程基线；将 **π0.5 完整机器人预训练权重的微调＋RTC** 提升为主要 VLA 候选，包含全量微调的正式参考。只有 D1 来源、时序和闭环质量通过后才训练。
3. 优先补学生状态上的纠错和接触阶段数据，并把推理调度作为独立实验因素。不要只依据离线 loss 选择模型。
4. GR00T N1.7 作为后续部署/新本体对照；LingBot-VLA 2.0 先借鉴数据质量和未来特征预测，不一开始复刻 MoE、双教师与多本体预训练。
5. 电机执行频率、策略推理频率、语义规划频率分别测量。当前没有 Orin 80M/5-step/6–8ms 或硬实时 100 Hz 的本项目验收。
6. 保留 RL 作为中后期的条件性补充：用户明确要求根据届时效果决定，已达到任务目标则可以不做，仍有性能瓶颈则继续用 RL 改进。先修正标定、数据与执行时序问题；若接触、离合、恢复或长程成功率仍不足，再冻结针对该瓶颈的奖励、算法与预算。真实 RL 依赖短程控制、物理复位、自动评分与故障恢复；RECAP、RLPD 与 Flow Matching 的结合需准确的策略更新/动作执行语义，不作无人值守几小时达到人类水平的承诺。

## 实施与记录

本轮只做来源核验、设计与文档更新；未接入 v1 模型、安装 FSR、下载模型权重、连接机器人、改变 VM、分配 GPU 或训练。新 [Kimi v1 任务合同](../tasks/leap-v1-full-rebaseline.zh-CN.md)为已准备，尚未派发；旧 v1/v2 任务书保留历史状态，不能直接复用旧账户命令或重跑旧作业。

所有后续远程派发先读取本地私有账户政策，使用已切换的本人身份；访问与环境仍按当前本地验收状态处理，账户信息不进入公开仓库。Kimi 继续负责具体实现与运行；协调者负责设计、审查、集成和发布。
