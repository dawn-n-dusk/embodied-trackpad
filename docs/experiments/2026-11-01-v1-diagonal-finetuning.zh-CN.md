# 在已有策略上继续全量微调：第一轮斜向纠错

2026-11-01。本轮从已验收的 74,640 参数 MLP 策略开始，保留全部权重与原输入归一化；并非随机初始化，也不是 π0.5。新数据采用新优化器和采样器；同一次训练中断恢复则保留优化器、随机数和采样位置。这两类接续已分别核验。

单张 H800 的实际分配运行 19 秒，完成 500 次主训练更新。训练内部另做一次恢复对照；外部从第 100 步真实恢复到第 101 步，另做一次对照。训练已结束，资源释放。第 0 步参与验证集选优，最终选中第 400 步；外部恢复分支只用于验收，不作为候选模型。

协调者独立重算 NumPy 前向与分集指标，并在 CPU 上读取全部 10 个 Torch 检查点：初始六组权重逐值相同、归一化全程不变、AdamW 六组计数与步数一致、导出精确对应第 400 步。外部恢复起点的模型/优化器/随机状态/采样位置与内部第 100 步文件一致；真实恢复更新和对照的差异为零。

取回阶段曾遇 SSH/SFTP 断连，原调度调用超时；保存已提交作业身份后，仅恢复取回，没有重提交。最终传输清单 24/24 文件散列一致。作业内清单记录 stdout 时日志尚在增长，只有该项旧散列过期；最终传输散列已核对。训练报告的 hold baseline 属于训练集，不能拿它作测试集基线；独立重算斜向测试 hold baseline 为 0.000414259 rad。
