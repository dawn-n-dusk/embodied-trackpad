# 单次轻触教师诊断：避免按压但未完成移动

采用冻结的 `pointing-light` 配置，仅把切向停止阈值从 1.1 N 降为 0.9 N，法向目标仍为 0.8 N。种子 3、对角目标、原物理/动作/视觉合格线不变。

独立审核了 120 张截图、5,550 个物理步、3,000 个视觉控制子步和 165 条触控消息，控制到触控消息的对应关系与原始散列一致。17 个运行源码、14 个资源及原生应用二进制与冻结来源一致，应用已释放、退出。最大穿透 0.6603 mm，连续无接触释放 2.062 s。

从首次物理接触第 1,007 步到清理结束共 4,544 步，最大法向力 0.96226 N；首次 GUI 触控消息在第 1,450 步。视觉段最大 0.94228 N，触控消息最大 0.95819 N，均未达到原生点击的 1.0 N 按下阈值。没有改变点击状态机或蓝色目标检测条件。

**定位失败**：初始误差 18.1426 px，末次观测 18.5430 px，120 个动作周期耗尽。最后一张截图发生在最后一组动作之前，因此终止误差缺失，不能用 18.5430 px 冒充最终误差。该回合不与先前三个普通模式的成功混算，也不进入训练集。

实际回合 14.44 s，Kimi 调度 124.3 s，独立离线审核约 8.79 s。后续由 Kimi 分析原始法向调整与切向门控是否造成停滞，先保存可核验诊断，再选择单一小改动。此处未启动新优化器或直播。
