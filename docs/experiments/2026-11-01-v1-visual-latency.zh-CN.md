# 视觉链路的离线解码测量

低目标力教师的四个方向诊断中，一例因截图年龄超过 250 ms 而停止。以下测量使用已经保存的六张 800×600 PNG，没有新采集、仿真或优化器运行。

每张图预热一次、计时五次。当前解码器共调用 36 次，其中 30 次计时；解码中位数 78.979 ms、p95 251.340 ms、最大 350.226 ms。像素提取中位数 2.943 ms、最大 2.980 ms。协调者根据原始计时独立重算汇总，核对六张图片散列和尺寸未变。

该环境没有安装 Pillow，候选分支没有执行，也没有任何候选像素一致性结论。代码审查发现未执行分支误把已解码数组传入 BytesIO，下一任务必须在新文件中纠正，旧报告保留。Kimi 调度耗时 154.2 s，实际执行和缓存 token 记录见[结构化回执](../../experiments/records/v1-visual-decode-benchmark-accepted-20261101.json)。Token 记录不是会员计费金额。

这些数据说明现有解码器可能消耗较多帧龄预算；当时的失败回合没有记录分段计时，因此不能直接归因。250 ms 合格线继续保持，失败仍计入分母。

下一步在本项目既有虚拟环境中仅添加 Pillow 12.0.0 的二进制包，保留安装报告和包清单，再对相同六张图测量原解码器与候选的逐像素一致性和耗时。安装失败即停止，不改变其他包；候选测量成功也不直接修改生产链路或启动新回合。
