# Sharpa 首轮实际学习与续训记录

SharpaWave 右手和临时 Panda 七轴臂已通过原生 PhysX 接触、相对触控板位移、GUI 点击和离指链路生成训练轨迹，并实际训练了视觉 BC 与 SuperMimic 风格的世界模型策略。结果仍属于早期工程实验，不能据此宣称已经具备可靠电脑操作能力。

| 路线 | 已核验的参数更新 | 自主原生仿真检查 | 证据边界 |
|---|---:|---|---|
| 视觉 BC，seed 42 | 64 步，再从完整检查点恢复到 65 步 | 第 64 步策略 0/2，800 次环境动作，两次均到步数上限 | 只用了 3 条成功专家轨迹、478 个动作；两次测试不足以评估泛化 |
| 世界模型，seed 0 | 动力学 2,000；actor 5,000；critic 5,000 | 结果文件报告 1/2，714 次动作；一次超时，一次点击后离指 | 完整权重及三个优化器状态已核验；未保存逐步轨迹/配对视频，任务证据限于运行源与结果文件 |
| BC + 纠错 / PPO | 0 / 0 | 尚无实际成绩 | 纠错标签与掩码修复通过软件测试，不等于已执行 DAgger 或 PPO |

两次策略检查使用了不同目标和不同训练量，不能将 0/2 与 1/2 当作方法优劣比较。固定安装、增益和相机条件的 100 次评测尚未完成。世界模型训练日志中的想象回报不是实际环境回报。

初始共同数据 `common-v1` 有 10 条唯一轨迹、1,987 个动作：训练 6 条/1,274 动作（其中 3 条成功、478 动作可用于 BC），验证 2 条/350 动作，测试 2 条/363 动作。验证和测试未进入优化器。原始记录不变；训练集的首帧时间戳和失败截断标记通过有来源的派生副本修正，逐数组比对确认其他内容未变。旧采集入口的源码清单存在覆盖缺口，因此仅作为明确记录局限的首轮工程训练集。

数据来自依靠模拟器反馈的专家控制器。YouTube 的动作/结果素材仍是参考视频，没有被冒充为机器人关节动作标签。BC actor 只接收屏幕 RGB、腕部 RGB、关节状态与接触/有效性掩码；GUI 真值只供专家和评测使用。动作通过 29 个关节目标增量进入物理引擎，不直接写光标或点击坐标。

纠错实现已修复：用学生真实到达状态上的 `teacher_action` 训练，而非模仿学生自己的已执行动作；无效标签不计损失；拒绝把普通专家数据作为纠错集重复加入；在模拟器关闭前保存数据索引。旧的单步恢复诊断曾把普通专家数据误记作 478 条纠错标签，已明确排除，实际纠错数据仍为零。

本轮在实验室 RTX 服务器执行，没有提交新的 SuperPOD 作业，也没有运行真实 Mac 输入或灵巧手硬件。所有成绩保留原任务定义：点击目标后食指测得接触力低于 0.1 N 才成功；这是未校准的仿真力阈值，不是真实触控板电容识别能力。

扩量共同集已冻结为111条唯一轨迹：训练107条，其中69条成功、10,217动作进入BC；其余真实失败保留供动力学学习。验证/测试仍为原始2+2条，原始manifest与NPZ校验和不变。并行编号冲突通过采集器命名空间派生视图解决，原始未覆盖；未来采集代码已改用独立运行UUID。扩量BC从65步恢复，已完成并核验20,000步，27个参数张量改变、权重有限。单批128次采集共报告85次专家成功；冻结后才完成的27条轨迹尚未进入本次优化器，不能把全部85条都称为已入训。扩量策略的新目标自主评测已完成0/2（800次动作），见下述原始轨迹复核。

修正后的世界模型评测使用上一步已观察奖励作保持基线，latent误差按相同预测步数比较；原报告保留。1/4/8步的关节、接触和奖励误差仍高于保持基线，暂不支持模型质量改善结论。98项针对性软件检查通过，但不替代实际任务评测。详见[机器可读记录](../../experiments/records/sharpa-first-training-and-expansion-20261118.json)。历史诊断的零接触、零训练结果保持原样，不被本次进展覆盖。

20,000步策略在两个未入训目标上的结果均失败：目标(172,354)的光标距离186.8→204.5px，目标(169,272)为154.4→150.4px。两次均有实际食指接触（峰值2.36/2.92N）和光标位移，其余手指测得接触力为0；没有目标点击，400步后由评测上限结束。已保存并独立核验每次401帧屏幕/腕部视频及原始动作、关节、接触、光标轨迹。第一条配对关键帧已人工观看。

私有评测脚本仍有关闭模拟器后才写汇总的问题，所以汇总由已落盘的原始轨迹重建，没有重跑或覆盖原始数据。400步外部上限未写入原始truncated数组，原始保留为诊断，不能直接作为合格训练轨迹。两条目标没有与训练目标坐标重合，但仍是固定场景的少量检查。下一阶段重点是学生实际偏离状态的纠错数据，以及固定的视觉闭环评测；现有两条路线均未证明可靠泛化。[评测原始数据摘要](../../experiments/records/sharpa-bc20000-evaluation-20261118.json)。
