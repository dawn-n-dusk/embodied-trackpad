# LEAP v1 视觉控制：先保持接触法向，再修正屏幕误差

首个 seed 2 视觉回合已证明截图会改变后续关节命令，真实动力学触点也能驱动隔离 GUI；但指向误差从 24.32 px 降到 14.89 px 后停止改善，未通过 3 px 标准。原始失败结果保留在[运行记录](../../experiments/records/v1-near-seed2-runtime-20261031.json)。

## 已定位的问题

旧规划器把平面位移和接触高度放在同一个带阻尼的最小二乘问题中。记录中的第 20 次规划要求法向下降 0.200 mm，雅可比却预测上升 0.121 mm；初始要求保持高度时，也预测上升 0.196 mm。因而延长回合并不能解决已经失去接触的问题。

这些数值来自已执行回合的雅可比和命令，描述的是局部运动预测。它们不是实际位移，也不能单独证明所有接触丢失都由该项造成。

## 修正方法

令雅可比的法向行为 `n`，裁剪后的高度修正为 `z`：

```text
d_z = n * z / (n·n)
P   = I - n nᵀ / (n·n)
A   = J_xy P
r   = target_xy - J_xy d_z
dq  = d_z + P Aᵀ (A Aᵀ + λ² I)⁻¹ r
```

法向先满足 `n·dq = z`，平面修正位于法向约束的零空间。若关节增量或剩余量程不够，整个四维增量乘同一个比例，避免逐通道裁剪破坏法向约束。所有非食指通道保持原值，原有 16 通道接口和 P1 接触模型保持不变。

该约束只在当前雅可比的一阶近似下成立。实际执行仍受伺服跟踪、摩擦、接触变形和有限步长影响，必须重新通过真实求解器回合验收。规划器仍是使用仿真雅可比和高度的特权教师，不是学习策略。
