# LEAP v1 首批训练数据验收

2026-11-01：12 个固定近目标教师回合的派生索引通过独立审核，可用于受控的小策略基线。训练器和实际优化器运行仍需分别验收。

| 项目 | 实际结果 |
|---|---|
| 完整回合 | 12 / 12 |
| 动作前样本 | 674 |
| 训练 / 验证 / 测试 | 453 / 141 / 80 |
| PNG（包含终止帧） | 686 |
| 动力学步 / 视觉控制子步 | 47,450 / 16,850 |
| 触控消息及应答 | 1,214 |
| 审核器检查 | 84 通过，0 失败、0 跳过 |

按目标类冻结整回合划分：训练 0、2、3、5、6、8、9、11；验证 1、7；测试 4、10。旧诊断回合不进入这批数据，不按相邻帧随机切分。

模型数值输入为图像推断的二维目标误差、16 维关节位置、16 维速度和16 维上次实际参考。PNG、时钟和传感器缺失元数据保留作证据，不拼进模型特征。FSR、电机电流和腕部图像缺失，保持 null 和 false 有效掩码。

每个动作标签包含实际执行的 25 × 16 个关节参考。逐步增量由相邻实际参考相减，不能把相对于块起点的累计偏移当成单步增量。25 × 2 ms 是50 ms仿真时间，不代表实测墙钟频率。动作结束时间取最后一个实际执行物理步的时间，终止截图没有动作标签。

独立复核将全部674行与原始状态、控制、PNG像素误差、动作索引及元数据逐项比对，确认758个原始文件散列未变。原始和候选文件的 `training_eligible=false` 不被改写；单独的本地审批回执绑定该派生索引。优化器另需绑定已审核训练源码和资源预算。

审核器检查总压力、1 mm穿透限制、向量形状、触控应答、图像与动作因果关系、实际离板、冻结源码及配置。多个原始接触点可能属于同一根手指，触控消息数量按聚合后的手指数检查。此前因此误拒绝的两个回合及旧导出保留。

这批数据来自同一场景和初态的特权教师，不是学习策略成功或任意Mac操作能力。截图时钟偏移和不确定度未保存，历史跨时钟帧龄精度不能认证。后续按[小策略合同](tasks/v1-small-policy-smoke.zh-CN.md)验证优化器、恢复、部署数值一致性和独立闭环。

详细来源、散列、耗时和限制见[验收记录](../experiments/records/v1-pilot-index-accepted-20261101.json)。原始图像、索引和运行许可保持私有。
